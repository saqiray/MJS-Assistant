**MJS Assistant** is a free, local AI assistant for **Termux, Android and Kali Linux**.

It uses `llama.cpp` and GGUF models to run AI locally on your device, without requiring a cloud AI API.

## 🚀 Features

- 📴 Local / offline AI
- 📱 Designed for Termux and Android
- 🐉 Kali Linux support
- 🧠 GGUF model support
- ⚡ Powered by llama.cpp
- 💬 English, Urdu and Roman Urdu
- 🛠️ Linux command assistance
- 🔍 Error analysis and troubleshooting
- 🔐 User confirmation before command execution
- 🆓 Free and open source

## 📋 Requirements

Recommended starting hardware:

- Android + Termux
- ARM64 / aarch64
- 6–8 GB RAM or more
- Python 3
- Git
- CMake
- Clang / build tools
- llama.cpp
- A compatible GGUF model
